NASA MISSION ARCADE
===================

Abrí index.html con Visual Studio Code / navegador.

Archivos:
- index.html
- spirit-opportunity.html
- voyager.html
- curiosity.html
- pioneer.html
- css/styles.css
- js/script.js

Para agregar el cortometraje:
1. Creá cortometraje.html, o
2. Cambiá el enlace del botón dentro de spirit-opportunity.html por tu video/página.

Traducción:
- El botón de idioma cambia textos que tengan data-es y data-en.
- Para agregar más textos bilingües, usá:
  <p data-es="Texto español" data-en="English text">Texto español</p>

Fuentes:
Los datos de las misiones se basan en páginas oficiales de NASA Science y NASA/JPL.
